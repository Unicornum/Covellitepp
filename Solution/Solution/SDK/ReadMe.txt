
Для подключения SDK к проектам решения необходимо:
- Запустить install.cmd.
- Файлы Directory.Build.targets и Externals.Error.props скопировать в корень
решения (если нужно подключить только один проект, поместить файл в папку этого
проекта; также можно поместить его в любую папку в иерархии решения - SDK будет
подключено ко всем проектам внутри этой папки).
